# Как подключиться к PIX-VPN

После оплаты бот пришлёт вам **ключ** — это длинная ссылка, которая
начинается с `vless://...` или `https://sub.northline-vpn.xyz/...`. Сам по
себе ключ ничего не делает — его нужно вставить в **VPN-приложение**
(клиент). Ниже список приложений, которые мы рекомендуем, и пошаговые
инструкции для каждой платформы.

## 2. Где взять ваш ключ

После успешной оплаты в боте `@pix_vpn_robot` вы увидите сообщение:

```
✅ Вы успешно оплатили заказ #N

Ваш ключ:
vless://xxxxxxxx@server.northline-vpn.xyz:443?...#PIX-VPN
```

или

```
Ваш ключ:
https://sub.northline-vpn.xyz/s/xxxxxxxxxxxx
```

**Скопируйте всю эту ссылку целиком** — это и есть ваш VPN-ключ.

> **Важно**: ключ можно использовать на нескольких устройствах одновременно
> (если вы выбрали тариф с 2+ устройствами). Подписку **не нужно** покупать
> отдельно для каждого телефона/ноутбука — просто вставьте один и тот же
> ключ во все ваши клиенты.

## 3. Подключение — пошагово

Главный приём универсальный для **всех** приложений ниже:

> **Скопировали ключ → открыли приложение → нажали «+» (или «Импорт»,
> «Добавить из буфера обмена») → подключились.**

Большинство клиентов **сами читают ссылку из буфера обмена** — нужно
только тапнуть по плюсу. Подробности по конкретным приложениям:

### V2RayTun (iOS / Android / macOS)

1. Скопируйте ключ из бота (зажмите на ссылке → «Копировать»).
2. Откройте **V2RayTun**.
3. Нажмите **«+»** в правом верхнем углу.
4. Выберите **«Добавить из буфера обмена»** (или «Импорт из буфера
   обмена», в зависимости от языка). Приложение само подхватит ссылку.
5. В списке появится новый профиль — обычно с именем **PIX-VPN**.
6. Нажмите на этот профиль, чтобы он стал активным (подсветится).
7. Нажмите большую кнопку **подключения** в центре экрана.
8. На iOS система спросит разрешение «Добавить VPN-конфигурацию» — нажмите
   **Разрешить** и введите код-пароль/Face ID.
9. Готово — иконка VPN появится в статус-баре. Можно проверить, что
   всё работает: откройте `https://2ip.ru` — страна должна измениться.

### Happ (iOS / Android)

1. Скопируйте ключ из бота.
2. Откройте **Happ**.
3. Нажмите **«+»** или иконку **«Импортировать»**.
4. Выберите **«Из буфера обмена»** — Happ вставит ссылку автоматически.
5. Тапните по созданному профилю → **подключиться**.
6. Разрешите добавление VPN-конфигурации (запрос системы).

### Hiddify (Android / Windows / macOS / Linux)

1. Скопируйте ключ.
2. Откройте **Hiddify**.
3. Нажмите **«+»** (или «Add a profile», «Добавить профиль»).
4. Выберите **«Add from clipboard»** или **«Import from clipboard»**.
5. Профиль появится в списке. Нажмите на большую кнопку питания
   в центре экрана, чтобы подключиться.

### Shadowrocket (iOS, платный)

1. Скопируйте ключ из бота.
2. Откройте **Shadowrocket**.
3. На главном экране сверху появится плашка **«Add a server from
   clipboard?»** — нажмите **Add**.
4. Если плашки нет — нажмите **«+»** в правом верхнем углу → выберите
   **«Type: VLESS»** → вставьте ссылку.
5. Включите тумблер рядом с сервером.
6. Нажмите большой переключатель в верхней части экрана (Not Connected
   → Connected).

### Streisand (iOS)

1. Скопируйте ключ.
2. Откройте **Streisand**.
3. Нажмите **«+»** → **«Add from Clipboard»**.
4. Выберите профиль из списка.
5. Нажмите тумблер «Connect».

### v2rayNG (Android)

1. Скопируйте ключ.
2. Откройте **v2rayNG**.
3. В правом верхнем углу нажмите **«+»** → **«Импорт config-а из
   буфера обмена»** (Import config from Clipboard).
4. Появится профиль «PIX-VPN».
5. Долгим нажатием выберите его как активный.
6. Нажмите большую кнопку **V** в правом нижнем углу.
7. Разрешите создание VPN-подключения.

### Hiddify Next / Nekoray / v2rayN (Windows)

1. Скопируйте ключ.
2. Откройте приложение.
3. **Hiddify Next**: «Add Profile» → «From Clipboard».
   **Nekoray**: меню **Program → Add profile from clipboard**
   (или `Ctrl+V`).
   **v2rayN**: **Серверы → Импорт из буфера обмена**.
4. Выберите профиль в списке → **Start** / **Подключить**.
5. На первом запуске Windows может спросить про сетевую конфигурацию —
   разрешите.

## 4. Если ключ — это **подписочная** ссылка (subscription URL)

Иногда вместо `vless://...` бот присылает ссылку вида
`https://sub.northline-vpn.xyz/s/...`. Это **подписка**: одна ссылка, по
которой клиент сам забирает один или несколько серверов и обновляет их,
если они меняются. Принцип тот же, но в приложении пункт меню называется
по-другому:

- **V2RayTun / Happ / Hiddify**: «+» → «**Добавить подписку**» (Add
  Subscription) → вставить ссылку → **Обновить**. После обновления в
  списке появятся серверы.
- **Shadowrocket**: «+» → **Subscribe** → вставить URL.
- **v2rayN / v2rayNG**: меню «Подписки» → «Добавить» → вставить URL → **Обновить
  подписку из буфера обмена**.

Дальше — выбираете сервер и подключаетесь.

## 5. Частые проблемы

**Не подключается, бесконечная загрузка.**
Закройте VPN, выключите-включите Wi-Fi / мобильный интернет, попробуйте
ещё раз. Если не помогает — попробуйте другое приложение из списка
выше: иногда конкретный клиент конфликтует с конкретной версией iOS
или Android.

**«Конфигурация неверна / Invalid config».**
Скорее всего, при копировании ключа попал лишний символ (пробел,
кавычка, перенос строки). Зайдите в бота, ещё раз скопируйте ссылку
целиком, удалите старый профиль в приложении и добавьте заново.

**Подключился, но интернет не работает.**
Проверьте, что профиль в приложении действительно **активен** (выделен
галочкой / точкой). Иногда после добавления нужно нажать на профиль
ещё раз. Также проверьте, что **сама подписка не закончилась** — в боте
в разделе «Профиль» видно дату окончания.

**На iOS просит «доверить разработчику».**
Это нормально только для приложений, которые ставятся **не из App Store**.
Все приложения из нашего списка — официальные, в App Store. Если просит
такое окно, значит вы поставили приложение через TestFlight / .ipa —
зайдите в **Настройки → Основные → VPN и управление устройством** и
доверьте разработчика. Но проще поставить версию из App Store.

**Слишком долго грузятся сайты / низкая скорость.**
Скорость зависит от конкретного приложения и от вашего интернета.
Попробуйте сменить клиент (v2rayTun ↔ Happ ↔ Hiddify) — иногда
помогает. Также не забывайте, что на тарифе с несколькими устройствами
все они делят пропускную способность.

**Не получается с первого раза.**
Напишите нам в **поддержку прямо в боте**: «Поддержка → Создать тикет».
Опишите, какое у вас устройство, какое приложение, и что именно не
работает (скриншот ошибки приветствуется). Мы обычно отвечаем
в течение нескольких часов.
